# 场景识别词典

麦途的每条场景标签都由这里的规则触发。规则是透明的，命中依据会写进 `evidence`，叙事层必须引用。

**欢迎 PR 补充**。新规则请附：触发关键词/时间窗、至少一个真实场景描述、不会误伤的反例。

## 店名关键词 → 场景

匹配方式：店名小写化后「包含」匹配。

| 场景 | 关键词 |
|---|---|
| 出行慰藉 | 机场、火车站、高铁站、高铁、GTC、航站楼、客运、口岸、候车 |
| 医院守护 | 医院、妇幼、人民医、中医 |
| 校园日常 | 大学、学院、中学、小学 |
| 写字楼补给 | 写字楼、商务、金融城、产业园、大厦 |
| 商圈逛吃 | 万象城、万达、吾悦、银泰、大悦城、印象城、天街 |

## 时段 → 场景

| 场景 | 时间窗 |
|---|---|
| 早班开场 | 05:00–10:30 |
| 午间补充 | 10:30–14:00 |
| 下午茶 | 14:00–17:30 |
| 晚餐 | 17:30–21:00 |
| 深夜补给 | 21:00–次日 05:00 |

## 关系场景

| 场景 | 规则 |
|---|---|
| 一单多点 | 同店 30 分钟内连续多单 |
| 新店打卡 | 该门店首次出现 |
| 老地方 | 同一门店第 3 次及以上 |

## 整单模式

门店多样性一律按「到访」口径统计——同店 30 分钟内的连点合并为一次到访，避免「在机场连吃两顿」被算成「去了两次机场」。

| 模式 | 规则 |
|---|---|
| 天涯路人 | 出行场景到访占比 ≥ 15% |
| 本地日常 | 最常去门店的到访占比 ≥ 40% |
| 早餐型 | 早餐场景订单占比 ≥ 40% |
| 深夜型 | 深夜场景订单占比 ≥ 25% |
